# Tenant Config Migrations (v1)

Migration scripts for upgrading tenant configurations **from v1 to v2**.

## Status

No migrations exist yet — v1 is the initial schema version.

When v2 is introduced, migration scripts will be added here following the contract defined in [../../docs/MIGRATION-STRATEGY.md](../../docs/MIGRATION-STRATEGY.md).

## Naming Convention

```
v1-to-v2-<description>.ts
```

Example: `v1-to-v2-rename-feature-flags.ts`
